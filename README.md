# Proyecto-final-Programaci-n
Este repositorio contiene el código utilizado para limpiar, organizar y estandarizar tres bases de datos utilizadas en el Taller Final de Limpieza y Preparación de Datos.
El objetivo es:
Corregir errores de codificación en nombres de columnas.
Unificar formatos numéricos.
Añadir variables geográficas faltantes.
Dejar listas las bases para análisis estadístico o geoespacial.
Las bases procesadas son:
empresas_10000.csv
poblacion_sisben.csv
establecimientos_comercio_2018.csv
